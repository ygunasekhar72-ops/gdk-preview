GDK case study — the same game, built twice

"Mini GTA" — top-down open-world driving for the browser: walk around a city, steal cars, knock over pedestrians (and get wanted stars for it), shake the police, deliver checkpoints for cash. Built twice by AI coding agents: once without GDK (a normal "just make it work" build), once through the GDK pipeline — declared spec, generated agent team plan, pillar playbooks, and machine-checkable quality gates that reject the build until every rule passes. Both games below are fully playable.

WITHOUT GDK 0 gates · 0 tests · unverified

  • Shape: one 1,041-line game.js + index.html. No spec, no tests, no build, no structure.
  • Timing: gameplay integrated with variable-delta requestAnimationFrame — behavior changes with frame rate.
  • Verification: syntax check only. Nobody can prove the physics, the FSM (if any), or the game loop actually work — you just… play it and hope.
  • Authority: no simulation/render separation to audit; logic and drawing are interleaved.
  • Works today. Honest point: ungoverned agents still ship playable games. GDK's value starts the moment you need proof, maintenance, or multiplayer.

BUILT WITH GDK gate report: PASS · 7/7 headless tests

  • Shape: declared gdk.game.json spec → planner output (5 phases, 5 specialists) → per-phase gate runs kept as the audit trail.
  • Timing: deterministic 60 Hz fixed-timestep sim, render decoupled. Same seed + same inputs = identical world, proven byte-for-byte over 600 ticks.
  • Verification: 7-test headless suite (determinism, input clamp, collision, FSM legality, crime events, scripted playtest) — GDK:ALL-TESTS-PASS.
  • Authority: GDK:AUTHORITATIVE sim boundary is grep-enforced; renderer reads, never decides.
  • Ready to grow: the same discipline is what server-authoritative multiplayer requires — see the multiplayer arena template.

What the gates actually caught during the rebuild

Real defects, caught by gates, fixed in the game (not in the gates):
  • Wall-glue physics — collision response made cars grind along walls at 0.07 m/s; the scripted-playtest gate exposed it → fixed with tangent sliding.
  • Dead missions after a bust — a BUSTED respawn stranded the FSM in FREE_ROAM so the mission could never complete → fixed (mission persists through arrest).
  • Two test bugs — an FSM case that asserted a legal transition must be rejected, and a bot chasing uncatchable moving cars → tests fixed, gates untouched.
Honest comparison: the ungoverned build also plays fine today. GDK doesn't make the first playable build appear — it makes the build provable, auditable, and safely extendable (multiplayer, replays, team handoffs). That is the gap it exists to close.
